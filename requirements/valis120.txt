# is upstream's 1.0.0 image (modules/local/register.nf), which the `valis_mirage` row uses.
#
# The harmonised versions hold here: VALIS 1.2.0's metadata (PyPI valis-wsi==1.2.0,
# requires_dist [FULL]) accepts numpy 1.26.4, scipy 1.15.3, scikit-image 0.25.2 and pandas
# 2.3.3, and STARE's requirements are the same lines, so `-r stare.txt` brings both the
# imaging stack and STARE's one pin (the benchmark reads images through stare.slide_io).
-c constraints.txt
-r stare.txt

# torch and torchvision come from PyTorch's own CPU index: the two VALIS rows run without a
# GPU, and the default PyPI wheel carries about 2 GB of CUDA libraries nothing here would
# load. This line reaches the whole resolve, so this file must never be `-r`-included from
# another one (requirements/torch-cpu.txt says the same of itself).
--extra-index-url https://download.pytorch.org/whl/cpu

# (pip 26.2.1) gives the same versions. NOTHING HERE WAS INSTALLED OR IMPORTED on the
