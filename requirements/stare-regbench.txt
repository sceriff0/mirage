# STARE image is containers/stare, which this file does not touch.
#
# THE SAME STARE, THE SAME STACK. `-r stare.txt` brings the pipeline image's lines as they
# are: the harmonised numpy / scipy / scikit-image / tifffile / zarr / numcodecs /
# imagecodecs and STARE's one pin, which therefore stays written exactly once in this
# repository. What this file adds is what the benchmark needs around the method and the
# pipeline does not (ruling R3.9a, 2026-10-10):
#   psutil   the benchmark reads a run's memory through psutil in every other method's
#            image; without it resources.Monitor falls back to /proc and STARE alone would
#            be measured by another instrument
#   pytest   the first command on the cluster runs test_external_methods.py inside the image
#   OpenCV   the tissue-level block (benchmarks/regbench/tissue.py: ORB, RANSAC, contours)
#            is the released ACCREDIT code and needs cv2. `tissue` and `score` run in THIS
#            image, so one OpenCV version stands behind a whole result
-c constraints.txt
-r stare.txt
